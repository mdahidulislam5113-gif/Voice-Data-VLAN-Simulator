Cisco Switch Port Configuration (IOS)

নিচের কনফিগারেশনের মাধ্যমে Fa0/1 পোর্টটি একইসাথে PC-এর Untagged Data (VLAN 10) এবং IP Phone-এর 802.1Q Tagged Voice (VLAN 20) গ্রহণ করে এবং Gi0/1 Trunk দিয়ে উভয় VLAN পাস করে: 

! 1. Create Data & Voice VLANs
Switch1(config)# vlan 10
Switch1(config-vlan)# name DATA_VLAN
Switch1(config-vlan)# vlan 20
Switch1(config-vlan)# name VOICE_VLAN

! 2. Configure Multi-VLAN Access Port (Connected to IP Phone + PC)
Switch1(config)# interface FastEthernet0/1
Switch1(config-if)# switchport mode access
Switch1(config-if)# switchport access vlan 10      ! PC Traffic (Untagged)
Switch1(config-if)# switchport voice vlan 20       ! IP Phone Traffic (802.1Q Tagged)
Switch1(config-if)# mls qos trust cos              ! Prioritize Voice CoS 5

! 3. Configure 802.1Q Trunk Port (Switch 1 <---> Switch 2)
Switch1(config)# interface GigabitEthernet0/1
Switch1(config-if)# switchport mode trunk
Switch1(config-if)# switchport trunk allowed vlan 10,20
