# Voice & Data VLAN Simulator

An interactive 3D network simulation that demonstrates how Voice VLAN and Data VLAN traffic travel through an IP Phone, an access switch, and a trunk link.

## Features

- 3D network topology visualization
- Data VLAN 10 and Voice VLAN 20
- 802.1Q VLAN tagging demonstration
- Ethernet Frame Inspector
- QoS value visualization
- Cisco IOS configuration reference
- Interactive packet-flow animations

## Network Topology

PC → IP Phone → Access Switch → Core/Distribution Switch

## Technologies Used 

- HTML, CSS, JavaScript
- Three.js
- WebGL
- Tailwind CSS

## How to Run Locally

1. Clone this repository.
2. Open `index.html` in a modern web browser.
3. Internet access is required to load the external CDN libraries.

## Note

This is an educational 3D visualization. It does not connect to physical network devices or capture real network traffic.
